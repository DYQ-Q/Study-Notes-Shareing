
好的，我们来详细讲解一下如何具体使用STM32的GPIO复用功能。这是一个非常核心且实用的知识点。

复用功能，顾名思义，就是让一个GPIO引脚不再作为通用的输入/输出口（GPIO_Mode_IN/OUT），而是将其“复用”为片上其他外设（如USART, I2C, SPI, Timer等）的专用功能引脚。

下面我们以一个最常见、最实用的例子——**配置USART1的发送和接收引脚**——来完整地讲解整个过程。

---

### 场景：配置USART1进行串口通信

假设我们使用的是STM32F103系列芯片，我们要使用USART1与电脑进行通信。根据芯片的数据手册，USART1的默认引脚是：
*   **TX (发送)**: **PA9**
*   **RX (接收)**: **PA10**

我们的目标是：将PA9配置为复用推挽输出，将PA10配置为浮空输入。

---

### 步骤1：查阅数据手册，确定引脚和复用功能

这是最关键的第一步。你需要查阅你所使用具体型号MCU的**Datasheet（数据手册）**，找到引脚定义表格。

在表格中找到PA9和PA10，你会看到类似下面的信息：

| Pin | Name | Type | I/O structure | Remap | ... |
| :-- | :--- | :--- | :--- | :--- | :-- |
| PA9 | **USART1_TX** | I/O | FT/... | **USART1_TX** | ... |
| PA10| **USART1_RX** | I/O | FT/... | **USART1_RX** | ... |

这个表格明确告诉我们，PA9可以作为USART1的TX引脚，PA10可以作为USART1的RX引脚。有些引脚还有**重映射**功能，意味着可以把这个外设功能移动到其他引脚上，我们这里先用默认引脚。

---

### 步骤2：配置GPIO引脚为复用功能模式

现在我们开始写代码。我们将使用标准外设库，因为它能清晰地展示每一步。

#### 1. 使能GPIO和USART1的时钟

任何外设使用前，都必须先打开它的时钟。GPIOA和USART1都挂载在APB2总线上。

```c
// 使能GPIOA和USART1的时钟
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_USART1, ENABLE);
```
**注意**：这里不仅要使能GPIOA的时钟，还必须使能USART1外设本身的时钟，两者缺一不可！

#### 2. 初始化GPIO引脚

我们需要分别配置PA9（TX）和PA10（RX）。

```c
GPIO_InitTypeDef GPIO_InitStructure;

// --- 配置USART1_TX (PA9) ---
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_9;
// 关键：配置为复用推挽输出模式
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP; 
// 串口通信通常需要较高的波特率，所以速度设置高一些
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &GPIO_InitStructure);

// --- 配置USART1_RX (PA10) ---
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_10;
// 关键：配置为浮空输入模式（或上拉输入，根据外部电路决定）
// 对于RX，通常使用浮空输入，因为信号由对方驱动
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IN_FLOATING;
// 输入模式下，Speed参数无效，但为了结构体完整性可以保留
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz; 
GPIO_Init(GPIOA, &GPIO_InitStructure);
```
**核心要点**：
*   **TX引脚（发送）**：必须配置为 **`GPIO_Mode_AF_PP`**（复用推挽输出）。因为MCU需要主动、强力地将数据位“推”到总线上。
*   **RX引脚（接收）**：必须配置为输入模式，通常是 **`GPIO_Mode_IN_FLOATING`**（浮空输入）。因为引脚是被动地等待外部设备发送信号。

---

### 步骤3：配置并使能外设本身（以USART1为例）

GPIO配置好只是“修好了路”，现在需要“发车”，也就是配置USART1外设本身。

```c
USART_InitTypeDef USART_InitStructure;

// 配置USART1参数
USART_InitStructure.USART_BaudRate = 115200;         // 波特率
USART_InitStructure.USART_WordLength = USART_WordLength_8b; // 数据位8位
USART_InitStructure.USART_StopBits = USART_StopBits_1;     // 停止位1位
USART_InitStructure.USART_Parity = USART_Parity_No;         // 无校验位
USART_InitStructure.USART_Mode = USART_Mode_Tx | USART_Mode_Rx; // 收发模式
USART_InitStructure.USART_HardwareFlowControl = USART_HardwareFlowControl_None; // 无硬件流控

// 初始化USART1
USART_Init(USART1, &USART_InitStructure);

// 使能USART1
USART_Cmd(USART1, ENABLE);
```

---

### 步骤4：使用外设进行通信

现在，一切都配置好了，你就可以调用USART1的库函数来发送和接收数据了。

```c
// 发送一个字节
void USART_SendByte(USART_TypeDef* USARTx, uint8_t data) {
    USART_SendData(USARTx, data);
    // 等待发送完成
    while (USART_GetFlagStatus(USARTx, USART_FLAG_TC) == RESET);
}

// 接收一个字节
uint8_t USART_ReceiveByte(USART_TypeDef* USARTx) {
    // 等待接收到数据
    while (USART_GetFlagStatus(USARTx, USART_FLAG_RXNE) == RESET);
    return USART_ReceiveData(USARTx);
}
```

---

### 其他外设的复用功能配置

配置流程是完全一样的，只是模式选择不同：

| 外设功能 | 引脚方向 | 推荐GPIO模式 | 标准库模式宏定义 |
| :--- | :--- | :--- | :--- |
| **SPI_SCK / MOSI** | 输出 | 复用推挽 | `GPIO_Mode_AF_PP` |
| **SPI_MISO** | 输入 | 浮空/上拉输入 | `GPIO_Mode_IN_FLOATING` / `GPIO_Mode_IPU` |
| **I2C_SCL / SDA** | 双向 | 复用开漏 | `GPIO_Mode_AF_OD` |
| **Timer PWM输出** | 输出 | 复用推挽 | `GPIO_Mode_AF_PP` |
| **Timer输入捕获** | 输入 | 浮空/上拉/下拉输入 | `GPIO_Mode_IN_FLOATING` / `GPIO_Mode_IPU` / `GPIO_Mode_IPD` |

**特别注意I2C**：I2C协议是“线与”逻辑，总线上的任何一个设备都可以将电平拉低。因此，**I2C的SCL和SDA引脚必须配置为复用开漏模式 (`GPIO_Mode_AF_OD`)**，并且通常需要外部接一个上拉电阻到VCC。

---

### 总结

使用复用功能的完整流程可以概括为以下四步：

1.  **查手册**：确定外设功能对应的GPIO引脚。
2.  **开时钟**：使能对应GPIO端口和外设的时钟。
3.  **配GPIO**：将引脚配置为正确的复用功能模式（`AF_PP` 或 `AF_OD`）或输入模式。
4.  **配外设**：初始化并使能该外设本身（如USART_Init, SPI_Init等）。

掌握了这个流程，你就能自如地使用STM32上几乎所有需要用到引脚的功能了。希望这个详细的例子能帮助你彻底理解复用功能的使用！
