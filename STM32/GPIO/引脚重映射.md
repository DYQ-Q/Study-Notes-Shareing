
好的，这是一个非常重要且实用的问题。GPIO引脚的**重映射**功能，是STM32设计灵活性的一个重要体现。它允许我们将某个外设的功能，从默认的引脚“移动”到另一组引脚上。

这在实际项目中有很大用处：
*   **解决引脚冲突**：当默认引脚已经被其他功能占用时。
*   **优化PCB布局**：将引脚移动到更方便布线的位置，使电路板更整洁。
*   **引脚功能复用**：让有限的引脚资源发挥更大的作用。

下面我们详细讲解如何实现重映射。

---

### 1. 重映射的工作原理

重映射功能并不是简单地改变一下GPIO的配置。它是由一个专门的**重映射和调试I/O配置寄存器（AFIO）**来控制的。

你可以把AFIO想象成一个“**交换机**”或者“**调度中心**”。默认情况下，外设A的信号线连接到引脚X。当你启用重映射后，AFIO内部的开关会切换，将外设A的信号线连接到引脚Y。

因此，要使用重映射，除了配置GPIO，**还必须配置AFIO**。

---

### 2. 实现重映射的步骤

我们继续以一个具体的例子来讲解：**将USART1的TX和RX从默认的PA9、PA10重映射到PB6、PB7**。

#### 步骤1：查阅数据手册和参考手册

1.  **数据手册**：首先确认PB6和PB7是否支持USART1的重映射功能。在STM32F1的数据手册中，你会看到：
    *   PB6: `USART1_TX` / `TIM4_CH1`
    *   PB7: `USART1_RX` / `TIM4_CH2`
    这说明PB6和PB7确实可以作为USART1的引脚。

2.  **参考手册**：这是最关键的一步！找到AFIO寄存器相关的章节。在STM32F1的参考手册中，你会找到 `AFIO_MAPR` 寄存器。在这个寄存器里，有 `USART1_REMAP` 这个位。
    *   `USART1_REMAP = 0`：USART1映射在PA9/PA10（默认）。
    *   `USART1_REMAP = 1`：USART1重映射到PB6/PB7。

#### 步骤2：使能AFIO时钟

AFIO也是一个外设，它挂载在APB2总线上。在使用重映射功能前，**必须先使能AFIO的时钟**。这是新手最容易遗漏的一步！

```c
// 使能 GPIOA, GPIOB, USART1 和 AFIO 的时钟
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_GPIOB | RCC_APB2Periph_USART1 | RCC_APB2Periph_AFIO, ENABLE);
```
**注意**：即使你只用到PB6和PB7，但如果你之前可能配置过PA9和PA10，最好把GPIOA的时钟也打开，以避免潜在问题。最保险的做法是把所有用到的端口时钟都打开。

#### 步骤3：配置重映射

调用标准库提供的函数 `GPIO_PinRemapConfig()` 来修改AFIO_MAPR寄存器。这个函数是专门用来做重映射的。

```c
// 启用USART1的完全重映射
// 这个宏定义在库中已经写好，直接调用即可
GPIO_PinRemapConfig(GPIO_Remap_USART1, ENABLE);
```
`GPIO_Remap_USART1` 这个宏就对应了参考手册里 `AFIO_MAPR` 寄存器中的 `USART1_REMAP` 位。

#### 步骤4：配置新的GPIO引脚

现在，我们需要像之前一样，去配置新的目标引脚 PB6 和 PB7。

```c
GPIO_InitTypeDef GPIO_InitStructure;

// --- 配置重映射后的 USART1_TX (PB6) ---
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_6;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP; // 依然是复用推挽输出
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOB, &GPIO_InitStructure); // 注意这里是GPIOB

// --- 配置重映射后的 USART1_RX (PB7) ---
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_7;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IN_FLOATING; // 依然是浮空输入
GPIO_Init(GPIOB, &GPIO_InitStructure); // 注意这里是GPIOB
```

#### 步骤5：配置并使能外设本身

这一步和没有重映射时**完全一样**。因为重映射是透明的，外设（USART1）本身并不知道它的物理引脚发生了变化。

```c
USART_InitTypeDef USART_InitStructure;
// ... 配置USART1参数（波特率、数据位等）...
USART_Init(USART1, &USART_InitStructure);
USART_Cmd(USART1, ENABLE);
```

---

### 3. 部分重映射与完全重映射

有些外设（如TIM、USART3等）不止一个重映射选项，会分为“部分重映射”和“完全重映射”。

*   **部分重映射**：只移动一部分功能引脚。
*   **完全重映射**：移动所有功能引脚。

在调用 `GPIO_PinRemapConfig()` 时，需要选择正确的宏。例如，对于USART3：
*   `GPIO_PartialRemap_USART3`：部分重映射
*   `GPIO_FullRemap_USART3`：完全重映射

具体如何划分，同样需要查阅**参考手册**中关于AFIO_MAPR寄存器的详细描述。

---

### 总结

实现GPIO重映射的完整流程是：

1.  **查手册**：确认目标引脚支持该外设的重映射功能，并找到重映射的控制位。
2.  **开时钟**：使能**目标GPIO端口**、**外设本身**以及**AFIO**的时钟。**（AFIO时钟最易忘！）**
3.  **启重映射**：调用 `GPIO_PinRemapConfig()` 函数，启用相应的重映射。
4.  **配GPIO**：按照外设功能要求，配置**新的目标引脚**的模式（输入/复用输出等）。
5.  **配外设**：像往常一样初始化并使能该外设。

掌握了重映射，你就能在PCB设计和引脚分配中获得极大的自由度，是STM32开发中一项非常高级且有用的技巧。
