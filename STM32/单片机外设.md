## GPIO

GPIO: General Purpose Input/Output,通用输入输出端口

### GPIO模式

GPIO有三种模式：

1. 输入模式
2. 输出模式
3. 复用功能模式
   如下表：

| 模式                  | 描述         | 用途 |
| --------------------- | ------------ | ---- |
| GPIO_Mode_AIN         | 模拟输入     | ADC  |
| GPIO_Mode_IN_FLOATING | 浮空输入     | 按键 |
| GPIO_Mode_IPD         | 模拟输入     | ADC  |
| GPIO_Mode_IPU         | 上拉输入     | 按键 |
| GPIO_Mode_Out_OD      | 开漏输出     | LED  |
| GPIO_Mode_Out_PP      | 推挽输出     | LED  |
| GPIO_Mode_AF_PP       | 复用推挽输出 | SPI  |
| GPIO_Mode_AF_OD       | 复用开漏输出 | SPI  |

> 注意：推挽输出和开漏输出区别：
>
> 1. 推挽输出：输出电平为高电平或低电平，输出电流为100mA。
> 2. 开漏输出：输出电平为高电平或低电平，输出电流为0mA。

### GPIO配置代码示例

标准库

```c
// 标准库-配置GPIOA0为上拉输入
void GPIO_Configuration(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
}
```

HAL库

```c
// HAL库-配置GPIOA0为推挽输出
void GPIO_Configuration(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    __HAL_RCC_GPIOA_CLK_ENABLE();

    GPIO_InitStructure.Pin = GPIO_PIN_0;
    GPIO_InitStructure.Mode = GPIO_MODE_OUTPUT_PP;
    GPIO_InitStructure.Pull = GPIO_PULL_NONE;
    GPIO_InitStructure.Speed = GPIO_SPEED_FREQ_HIGH;
    HAL_GPIO_Init(GPIOA, &GPIO_InitStructure);
}
```

## TIM

TIM: Timer,定时器

### TIM模式

TIM有三种模式：

1. 输入捕获模式
2. 输出比较模式
3. 通用定时器模式

### TIM配置代码示例

#### 通用定时器模式

$$
\begin{aligned}
T_{TIM}&=\frac{(PSC+1)\times(ARR+1)}{f_{TIM}}\\&=\frac{PSC + 1}{f_{TIM}} \times (ARR + 1)
\end{aligned}
$$

```c
// 标准库-配置TIM2为通用定时器模式
void TIM_Configuration(void)
{
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

    TIM_TimeBaseStructure.TIM_Period = 1000 - 1; // ARR寄存器值,自动重装载寄存器
    TIM_TimeBaseStructure.TIM_Prescaler = 7200 - 1; // PSC寄存器值，预分频器值
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStructure);
}
```

- ***TIM_Period(ARR)***
  自动重装载寄存器值，当CNT值达到该值时，CNT会重新从0开始计数(前提是计数器模式为向上计数或向下计数)。
- ***TIM_Prescaler(PSC)***
  预分频器值，用于将时钟频率除以该值，得到定时器时钟频率。决定CNT计数一次所需的时间，如PSC=7200-1，定时器时钟频率为72MHz/7200=1000Hz=1000$s^{-1}$，计数一次所需的时间为1ms（1/1000Hz）。
- ***TIM_ClockDivision(CKD)***
  时钟分频器值，用于将时钟频率除以该值，得到定时器时钟频率。一般设为1，即TIM_CKD_DIV1，不进行频分。其他值为TIM_CKD_DIV2~TIM_CKD_DIV256（$2^8$）。
- ***TIM_CounterMode(CT)***
  计数器模式，用于指定定时器的计数方向，向上计数、向下计数或中间计数，分别是TIM_CounterMode_Up、TIM_CounterMode_Down和TIM_CounterMode_UpDown。

#### 输出比较模式

```c
// 标准库-配置TIM2为输出比较模式
void TIM_Configuration(void)
{
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    TIM_OCInitTypeDef TIM_OCInitStructure;

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    TIM_TimeBaseStructure.TIM_Period = 1000 - 1; // ARR寄存器值,自动重装载寄存器
    TIM_TimeBaseStructure.TIM_Prescaler = 7200 - 1; // PSC寄存器值，预分频器值
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStructure);


    TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStructure.TIM_Pulse = 500 - 1; // CCR寄存器值，比较寄存器
    TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;
    TIM_OC1Init(TIM2, &TIM_OCInitStructure);
}
```

- ***TIM_OCMode***
  输出比较模式，用于指定输出比较模式，如PWM模式、强制输出模式、匹配输出模式等。
  - TIM_OCMode_Timing：定时模式，用于定时。
  - TIM_OCMode_Active：主动模式，当CNT==CCR寄存器值时，输出高电平。
  - TIM_OCMode_Inactive：被动模式，当CNT==CCR寄存器值时，输出低电平。
  - TIM_OCMode_Toggle：切换模式，当CNT==CCR寄存器值时，输出电平翻转。
  - TIM_OCMode_PWM1：PWM模式1，用于输出PWM信号。
  - TIM_OCMode_PWM2：PWM模式2，用于输出PWM信号，与PWM1相反。
  - TIM_OCMode_ForceHigh：强制输出高电平。
  - TIM_OCMode_ForcedLow：强制输出低电平。
- ***TIM_OutputState***
  输出状态，用于指定输出比较引脚的状态，如使能、禁用等。
- ***TIM_Pulse***
  比较寄存器值，用于指定输出比较的值，当CNT值等于该值时，输出比较引脚的状态会发生变化。
- ***TIM_OCPolarity***
  输出极性，用于指定输出比较引脚的极性，如高电平有效（TIM_OCPolarity_High）、低电平有效（TIM_OCPolarity_Low）。

#### 输入捕获模式

```c
// 标准库-配置TIM2为输入捕获模式
void TIM_Configuration(void)
{
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;
    TIM_ICInitTypeDef TIM_ICInitStructure;

    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    TIM_TimeBaseStructure.TIM_Period = 0xFFFF; // ARR寄存器值,自动重装载寄存器
    TIM_TimeBaseStructure.TIM_Prescaler = 0; // PSC寄存器值，预分频器值
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStructure);

    TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
    TIM_ICInitStructure.TIM_ICPolarity = TIM_ICPolarity_Rising;
    TIM_ICInitStructure.TIM_ICSelection = TIM_ICSelection_DirectTI;
    TIM_ICInitStructure.TIM_ICPrescaler = TIM_ICPSC_DIV1;
    TIM_ICInitStructure.TIM_ICFilter = 0x0;
    TIM_IC1Init(TIM2, &TIM_ICInitStructure);
}
```

- ***TIM_Channel***
  输入捕获通道，用于指定输入捕获通道，如TIM_Channel_1、TIM_Channel_2等。
- ***TIM_ICPolarity***
  输入捕获极性，用于指定输入捕获通道的极性，如TIM_ICPolarity_Rising（上升沿）、TIM_ICPolarity_Falling（下降沿）等。
- ***TIM_ICSelection***
  输入捕获选择，用于指定输入捕获通道的输入源，如
  - TIM_ICSelection_DirectTI（直接输入）
    将输入捕获通道的输入源连接到定时器的输入引脚。
  - TIM_ICSelection_ToggleTI（切换输入）
    将输入捕获通道的输入源连接到定时器的输入引脚，当输入源的电平切换时，定时器会记录当前的CNT值。
- ***TIM_ICPrescaler***
  输入捕获预分频器值，用于将输入捕获通道的时钟频率除以该值，得到输入捕获通道的时钟频率。常用的有TIM_ICPSC_DIV1（不进行频分）、TIM_ICPSC_DIV2（频分2）、TIM_ICPSC_DIV4（频分4）等。
- ***TIM_ICFilter***
  输入捕获滤波器值，用于对输入捕获通道的输入信号进行滤波，减少噪声。一般设为0x0，即不进行滤波。还可以设置为0x1、0x2、0x3等，分别表示1个、2个、3个时钟周期的滤波。

### 定时器计算公式

#### 定时周期计算公式

$$
\begin{aligned}
T_{TIM}&=\frac{(PSC+1)\times(ARR+1)}{f_{TIM}}\\&=\frac{PSC + 1}{f_{TIM}} \times (ARR + 1)
\end{aligned}
$$

其中，$f_{TIM}$为定时器时钟频率，$PSC$为预分频器值，$ARR$为自动重装载寄存器值。
定时时长参考表

| 定时器时钟频率 | PSC预分频器值 | ARR自动重装载寄存器值 | 定时周期 |
| -------------- | ------------- | --------------------- | -------- |
| 72MHz          | 7200          | 1000                  | 1ms      |
| 72MHz          | 7200          | 10000                 | 10ms     |
| 72MHz          | 7200          | 100000                | 100ms    |
| 72MHz          | 7200          | 1000000               | 1s       |

> 注意,寄存器数值范围与定时器有关：
> 16位定时器寄存器值范围：0-65535
> 32位定时器寄存器值范围：0-4294967295

#### 输出比较模式计算公式

输出比较模式用于控制PWM输出，通过设置比较寄存器的值，可以控制PWM信号的占空比和频率。

$$
\begin{aligned}
T_{PWM}&=\frac{(PSC+1)\times(ARR+1)}{f_{TIM}}\\&=\frac{PSC + 1}{f_{TIM}} \times (ARR + 1)
\end{aligned}
$$

其中，$f_{TIM}$为定时器时钟频率，$PSC$为预分频器值，$ARR$为自动重装载寄存器值。

$$
占空比：Duty\_Cycle=\frac{CCR}{ARR+1}
$$

其中，$CCR$为比较寄存器值，$ARR$为自动重装载寄存器值。
则PWM输出高/低电平时长的计算公式(控制舵机)为：

$$
\begin{aligned}
T_{High/Low}
&=T_{PWM}\times Duty\_Cycle\\
&=\frac{(PSC+1)\times(ARR+1)}{f_{TIM}}\times\frac{CCR}{ARR+1}\\
&=\frac{(PSC + 1)\times CCR}{f_{TIM}}
\end{aligned}
$$

输出高/低电平时长参考表

| 定时器时钟频率 | PSC预分频器值 | ARR自动重装载寄存器值 | CCR比较寄存器值 | 占空比 | PWM输出高/低电平时长 |
| -------------- | ------------- | --------------------- | --------------- | ------ | -------------------- |
| 72MHz          | 7200          | 1000                  | 250             | 25%    | 0.25ms               |
| 72MHz          | 7200          | 1000                  | 500             | 50%    | 0.5ms                |
| 72MHz          | 7200          | 1000                  | 750             | 75%    | 0.75ms               |

#### 输入捕获模式计算公式

原理：如设为上升沿捕获模式，则当上升沿到来时，CNT寄存器的值会被捕获到CCR1寄存器中，然后CNT寄存器会重新从0开始计数。通过读取CCRx(x=1,2,3,对应定时器的输入捕获通道)寄存器的值，可以计算出输入信号的周期，如下：

$$
\begin{aligned}
周期=T_{Input}
&=(CCRx+1)\times\frac{PSC+1}{f_{TIM}},x=1,2,3...\\
\end{aligned}
$$

且$T_{Input}$需小于$T_{TIM}=\frac{(PSC+1)\times(ARR+1)}{f_{TIM}}$,可以说$ARR$的值决定测量的量程。

$$
\begin{aligned}
频率=f_{Input}
&=\frac{1}{T_{Input}}
&=\frac{f_{TIM}}{(CCRx+1)\times (PSC+1)}\\
\end{aligned}
$$

如，PSC=7200-1,$f_{TIM}=72MHz$,则：

$$
\begin{aligned}
频率=f_{Input}
&=\frac{72MHz}{(CCRx+1)\times 7200}=\frac{10^4}{CCRx+1}Hz
\end{aligned}
$$

## IIC

IIC（Inter-Integrated Circuit），使用两条信号线：SDA（数据线）和SCL（时钟线）。SDA线用于传输数据，SCL线用于同步数据传输。IIC协议支持半双工通信，即设备之间可以相互通信，但是同一设备不能同时进行数据的发送和接收。

### IIC协议的基本工作原理

IIC协议的核心原则是：**SCL由主设备绝对控制，SDA在数据传输阶段由发送端控制，在接收阶段由接收端控制。** 并且有一个著名的“SCL高电平期间SDA必须稳定”的规则，即在SCL为高电平时，SDA必须保持稳定，不能改变。

| 通信行为                   | SCL状态 | SDA操作方                     | SDA状态                        | 说明                                                                  |
| :------------------------- | :------ | :---------------------------- | :----------------------------- | :-------------------------------------------------------------------- |
| **START (起始信号)** | 高电平  | **主设备**              | 高电平 → 低电平               | SCL为高期间，SDA产生下降沿，表示一次传输开始。                        |
| **STOP (停止信号)**  | 高电平  | **主设备**              | 低电平 → 高电平               | SCL为高期间，SDA产生上升沿，表示一次传输结束，总线释放。              |
| **发送数据位**       | 低电平  | **发送端** (主从皆可)   | 改变，低电平表示0，高电平表示1 | SCL低电平期间，发送端改变SDA状态                                      |
| **接受数据位**       | 高电平  | 无                            | 稳定                           | SCL高电平期间，SDA必须稳定，接收端读取数据。                          |
| **ACK (应答信号)**   | 低电平  | **接收端** (主收或从收) | 拉低SDA                        | 发送端释放SDA(输出高阻态)，接收端在SCL高电平期间拉低SDA表示收到数据。 |
| **NACK (非应答)**    | 低电平  | **接收端**              | 保持SDA高电平                  | 接收端不拉低SDA，SDA被上拉电阻拉高，表示接收失败或接收结束。          |

在标准IIC协议中，START信号和STOP信号只能由主设备产生。

>比如一次完整的IIC通信
>>1. 主设备发送START信号
>>2. 主设备在SCL低电平期间，改变SDA状态，当SCL为高电平时，接收端读取SDA状态，以此类推（一般是先发送从机地址，再发送数据）
>>3. 接收端接收完数据在SCL低电平期间拉低SDA（ACK），表示接收成功,相当于给主设备发送一个0
>>4. 之后该从设备发送数据，主设备读取数据了
>>5. 主设备在SCL高电平期间，拉高SDA,释放总线，结束一次通信
